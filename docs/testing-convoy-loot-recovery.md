# Convoy loot recovery failure modes

A temporary communication or observation hold preserves the coordinator's loot
identity but must suspend collection. Treating that hold as terminal retires the
identity locally, so restored defense cannot retry a transient native opening
error and the original Hunt never resumes. Preserve the owned control during
those holds without collecting, and resume native collection after defense
returns. Explicit removal, replacement, stale updates, cancellation, wrong realm
or instance, distant position and active combat must retain their existing
rejection behavior. In-flight passes still need a fresh subsequent observation;
a missing chest or a stale heartbeat alone never establishes completion.

The retained boundary test covers opening failure, communication suspension,
restored retry and actual observation completion. The existing native passive
Goo interruption journey must still prove the real kill, same Hunt identity,
exact native rewards for both owners and saved evidence.
